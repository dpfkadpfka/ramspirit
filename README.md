# RamSpirit

여러 AI 앱(ChatGPT·Gemini·Grok·Claude 등)과 일반 프로그램을 한 창에 나란히 띄우고, 질문 하나를 한 번에 보내는 윈도우 프로그램입니다.

## 내려받기

👉 **[RamSpirit.exe 내려받기](https://github.com/dpfkadpfka/ramspirit/releases/latest/download/RamSpirit.exe)**

1. 받은 `RamSpirit.exe`를 더블클릭합니다. (파란 보호 창이 뜨면 「추가 정보 → 실행」)
2. 자동으로 설치되고 바탕화면에 **RamSpirit** 아이콘이 생깁니다.
3. 처음 설정 창에서 칸 수와 칸마다 열 앱을 고르면 끝.

새 버전이 나오면 프로그램이 알아서 받아 둡니다. 다시 내려받을 필요가 없어요.

## 주요 기능
- 2·4·6·8칸, 칸마다 AI·웹사이트·설치된 프로그램 선택
- 아래 입력창에서 **모두에게 한 번에 보내기** (칸별 보내기 켬/끔)
- 칸별·전체 **새 대화**, 크게 보기, 끌어서 자리 바꾸기, 칸 크기 조절
- 창을 닫으면 안의 앱도 함께 닫힘 (Shift를 누른 채 닫으면 앱은 남김)
